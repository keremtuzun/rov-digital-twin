# Claim boundaries

- The current phase is software-first; it does not demonstrate a physical robot deployment.
- Synthetic telemetry, Unity results, visual fixtures and Failure Twin v0 states are not real-world
  inspection accuracy.
- Model 1 is not frozen until an approved checkpoint, dataset manifest and reproducible failure analysis exist.
- The telemetry classifier is vehicle-health diagnostics, not the visual Model 1 baseline.
- Model 2 is a research hypothesis, not a validated proprietary invention or confirmed damage assessor.
- The navigation twin simulates robot motion/viewpoints; Failure Twin v0 simulates hidden structural
  state; the separate 2D fixture only generates controlled visual evidence.
- Simulation parameters are not calibrated physical truth unless backed by system-identification evidence.
- Decision agents produce inspect/reinspect/viewpoint/unknown/escalate recommendations only.
- Diagnostic, perception, Model 2 and LLM paths cannot emit PWM, motor voltage/torque, servo commands or
  individual thruster forces.
- Unknown or unclear data licenses are not permission to download or train.
- Reports must identify data type, run ID, git commit, config, limitations, failed work and open gates.
