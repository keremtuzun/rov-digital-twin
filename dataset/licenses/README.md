# License evidence register

This directory stores small text snapshots or PDFs of the exact terms that governed an approved
asset at download time. A URL alone is insufficient because terms can change. Do not copy an entire
third-party website; save the applicable license text or official record, its retrieval date, and a
SHA-256 checksum. Asset-level caption/credit data belongs in the manifest.

Current source-level review (2026-08-23):

- NOAA Ocean Exploration: portal says all portal video is public domain; individual captions and any
  copyright exception still require inspection.
- TrashCan and SUIM: manual review because IRVLab describes its datasets as academic-research-only and
  TrashCan imagery originates from JAMSTEC J-EDI.
- FathomNet: licenses are selected per asset; only CC0 and CC BY 4.0 enter the automatic allowlist.
- DeepFish: project page does not expose a license; manual review.
- CoralNet: public/private source visibility does not establish ownership or a reuse license.

This register is an engineering control, not legal advice.
